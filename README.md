# 搜图酱

Mac 菜单栏搜图小工具。表情包、GIF、普通图片直接显示为可选网格；点击图片，放入飞书当前聊天输入框，最后由你确认发送。

技术栈：Swift、AppKit、WebKit、Carbon、macOS Accessibility、ImageIO、URLSession、NSPasteboard。无第三方运行时依赖、自建后端或数据库。

## 开始使用

1. 双击 `dist/搜图酱.app`，或双击 `启动.command`。
2. 在飞书里先点一下准备发图的聊天输入框。
3. 按 **Control + Option + 空格**打开搜图酱，输入关键词并回车。
4. 点击结果图片。已开启一键粘贴时，会返回飞书并执行粘贴；确认图片与收件人后，自行发送。

首次点击上方 **开启一键粘贴**，按提示进入系统设置 → 隐私与安全性 → 辅助功能，由你允许 **搜图酱**。若系统没有自动列出，可点 `+` 选择 `dist/搜图酱.app`。授权后关闭并重新打开搜图酱。此权限用于核对飞书输入框焦点与执行 ⌘V；工具不会执行回车发送，也不读取聊天消息。

未开启权限时，点图仍会复制图片，点击“返回飞书”再手动按 **⌘V** 即可。若飞书焦点在搜索框或其他位置，工具会提示先点击聊天输入框，不会向这些位置粘贴。macOS 权限是否已生效，以界面“一键粘贴已开启 ✓”为准。

## 其他操作

- **表情包 / GIF 动图 / 普通图片**：切换分类自动重新搜索。
- 每张图下方的 **仅复制**、**保存原图**、**查看来源**可单独使用。
- GIF 复制保留原文件；若飞书未将它显示为动画，可保存原文件后拖入聊天。GIF 分类返回静态图时会明确提示，不会自动粘贴一张静态预览冒充动图。
- **Esc** 收起窗口；快捷键再次打开。点窗口关闭按钮仍保留菜单栏入口；在菜单栏选择“退出搜图酱”可完全退出。
- 重新双击应用会唤出已有窗口，不会重复启动。
- 默认必应图片；百度图片为备用入口。搜索站点可能要求验证码，可切换引擎或用“在浏览器打开”手动处理。当前测试百度触发安全验证，必应可正常取得结果。
- 搜图酱对单个下载限制 25 MiB，并校验真实图片类型；有防盗链或不可访问的原图会提示失败，可换一张或查看来源。

## 文件及数据

应用不修改飞书安装包，不需要飞书机器人、API 密钥或企业应用。搜索词会交给所选搜索网站，缩略图与原图会访问相应图片站点。没有自建服务器或数据分析服务。

动图剪贴板使用系统临时目录 `FeishuImageHelper` 下的原文件，以便切回飞书后仍能粘贴；系统会管理临时目录，工具不会在退出时立即删除仍可能需要粘贴的文件。“保存原图”仅保存到你选择的位置。

图片搜索结果最多提取当前页面的 80 张；公开网页结构变化可能影响提取，保留“重试搜索”和“在浏览器打开”作为退路。软件不提供图片版权许可，需按来源要求使用。

## 重新构建与测试

运行已构建的应用不需要 Python、Node 或 Xcode。重新构建需要 Apple Command Line Tools（当前开发机已安装）和 macOS 13 以上；产物只包含构建机器架构，目前为 Apple Silicon。

```sh
./build.command
swift run CoreChecks
python3 Tests/network_checks.py
```

最后一项仅用于开发测试，使用 Python 标准库启动本机 HTTP 服务，不访问外网。覆盖真实 PNG、GIF、重定向、HTTP 错误、伪图片和过大下载。

应用使用本机 ad-hoc 签名，未作开发者公证；辅助功能权限由用户在本机授予。源码独立编写，联网参考见 [参考资料](docs/REFERENCES.md)，实际验证及限制见 [验证记录](docs/VALIDATION.md)。

重新构建后，macOS 可能要求重新允许辅助功能；请以“一键粘贴已开启 ✓”为准。此时可先使用“仅复制”和手动粘贴。
