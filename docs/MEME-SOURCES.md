# 专门梗图库升级

用户确认：专门梗图库优先，保留免费限额和通用搜索备用。

## 问题与选择

旧版只给通用搜索词追加“表情包”，缺少梗名、情绪和角色标签，容易混入素材网站与不相关照片。改为直接请求专门图库的公开 JSON API；普通图片继续保留通用搜索。

已对比：

- **memecub（本次采用）**：[接口文档](https://memecub.com/developers)及[项目](https://github.com/liyupi/memecub)。支持中文标签、角色、GIF、热门与最新排序。实测“绷不住了”“摸鱼”返回对应聊天梗图。免密钥额度为每个 IP 每天 20 次搜索；免费账号可自行申请更多额度，但本次不创建账号、不引入付费调用。
- **闪萌**：[官方说明](https://www.weshineapp.com/api)提供搜索、热门和神配图，但接入需要进一步核对合作与密钥条件，本次不使用他人应用的密钥。
- **ChineseBQB**：[GitHub 图库](https://github.com/zhaoolee/ChineseBQB)适合作为分类浏览／本地图库参考，不代表实时热梗榜。
- 部分第三方免费 API 实测转发相同的腾讯搜狗表情结果，不能作为多源独立性依据。

## 确定的行为

- 表情／热梗及 GIF 默认使用梗图库；请求原始关键词，不追加“表情包”。普通图切换到通用搜索。
- 提供相关、图源热门、最新收录三种排序，热门入口读取图源实际热门排序；不把固定推荐词冒充实时热榜。
- 显示来源，保留“仅复制”“保存原图”“查看来源”和原有草稿粘贴校验。
- 同一成功且非空的请求本地缓存：相关搜索 24 小时，热门／最新 15 分钟；缓存命中不调用 API。空结果不长期缓存，以便图源补收录后重试。
- 免费限额或服务故障明确提示；由用户选择通用图源，不静默回退，不绕过限额。
- 只发送用户输入的搜索词，不读取飞书聊天内容。缓存为本机结果 JSON，不在公共源码里保存密钥。

## 实施与验证

1. Core 新增请求构造、结果解析、重复过滤及有上限的磁盘缓存；先写失败检查，再实现。
2. 新增可取消的 API 客户端，处理无结果、格式错误、HTTP 402/429、网络错误；本机 HTTP 测试覆盖网络边界。
3. 浮窗接入默认梗图源、排序与热门入口；保留导航、结果世代和剪贴板令牌检查。
4. 实际中文梗词与热门列表验证、独立审阅、完整检查与构建；更新 README 和版本说明，再发布。

此图源的热门排名和新图收录由服务方决定，不承诺覆盖所有新梗或代表全网热度。
